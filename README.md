# 技能大爆炸

一个 Phaser 3 + TypeScript + Vite 构建的 2D 俯视角肉鸽割草战斗原型。

## 运行

```powershell
npm install
npm run dev
```

## 操作

桌面端使用 `W`、`A`、`S`、`D` 移动；手机端用左下角虚拟摇杆移动。玩家会每 0.5 秒自动攻击最近的敌人。敌人掉落经验晶体，靠近后会自动拾取；升级时用鼠标、触摸或数字键 `1`、`2`、`3` 选择强化。死亡后点击界面按钮或按 `R` 重开。

## 当前内容

- 4000 x 4000 世界与跟随摄像机
- 青绿色 Graphics 玩家
- 原创近战、远程、炮车三类小兵
- 红色晶体蛮兽与蓝色石甲守卫两类精英 Buff 怪
- 自动生成、追踪、接触伤害与生命值销毁
- 自动投射物攻击
- 真实经验条、等级、经验掉落与自动吸附拾取
- 暂停战斗的三选一升级：射速、伤害、多重射击、弹速、移速、生命
- 死亡结算与重开流程
- 全屏自适应画布、触摸摇杆与横竖屏自适应界面
- 生命、时间、击杀、技能槽和小地图 HUD
- 为 `SkillSystem`、`StatusSystem` 预留独立模块

当前没有主动技能、状态效果与手动暂停流程。
