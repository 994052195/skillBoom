# 技能大爆炸

一个 Phaser 3 + TypeScript + Vite 构建的 2D 俯视角肉鸽割草战斗原型。

## 运行

```powershell
npm install
npm run dev
```

## 操作

桌面端使用 `W`、`A`、`S`、`D` 移动；手机端用左下角虚拟摇杆移动。玩家会每 0.5 秒自动攻击最近的敌人；获得 `斩钢闪` 后，普攻改为直线斩击，并且每三次释放一道旋风。敌人掉落经验晶体，靠近后会自动拾取；升级时用鼠标、触摸或数字键 `1`、`2`、`3` 选择强化。死亡后点击界面按钮或按 `R` 重开。

## 当前内容

- 4000 x 4000 世界与跟随摄像机
- 青绿色 Graphics 玩家
- 原创近战、远程、炮车三类小兵
- 红色晶体蛮兽与蓝色石甲守卫两类精英 Buff 怪
- 自动生成、追踪、接触伤害与生命值销毁
- 自动投射物攻击，可通过奖励切换为 `斩钢闪`
- 真实经验条、等级、经验掉落与自动吸附拾取
- 暂停战斗的升级选择：射速、伤害、多重射击、弹速、移速、生命、穿透弹、环绕飞刃、斩钢闪及其专属强化
- 强化等级上限、升级前后数值对比与满级候选过滤
- 死亡结算与重开流程
- 全屏自适应画布、触摸摇杆与横竖屏自适应界面
- 生命、时间、击杀、技能槽和小地图 HUD
- 独立 `SkillSystem` 管理飞刃，`StatusSystem` 管理击飞等临时状态

## 强化与技能

| 强化 | 等级上限 | 每级效果 |
| --- | --- | --- |
| 连发核心 | 5 | 攻击间隔乘以 0.88，逐级取整；500ms 最终降至 264ms |
| 强击棱镜 | 5 | 普攻基础伤害 +10 |
| 分裂回路 | 4 | 每次攻击 +1 枚投射物，最多 5 枚 |
| 超导弹道 | 5 | 弹速 +16%，逐级取整 |
| 相位步伐 | 5 | 移速 +12%，逐级取整 |
| 生命核心 | 5 | 生命上限 +25，同时恢复 25 生命 |
| 穿透弹 | 3 | 额外穿透 1 个敌人，最多命中 4 个不同敌人 |
| 环绕飞刃 | 3 | 增加 1 把飞刃，最多 3 把 |
| 斩钢闪 | 1 | 将普攻切换为斩击；每三次释放旋风 |
| 风暴半径 | 4 | 斩钢闪距离 +60px |
| 风暴锋压 | 5 | 斩钢闪与旋风额外伤害 +10 |
| 旋风贯穿 | 3 | 旋风额外命中 +1 个目标 |
| 升空气流 | 3 | 旋风击飞时间 +150ms |

穿透弹按飞行路径顺序处理命中，每枚弹对同一敌人只伤害一次；与多重射击、弹速、伤害强化兼容。高速弹使用线段碰撞检测。

飞刃围绕玩家在 80px 半径上旋转，每次命中造成 15 伤害，同一敌人的所有飞刃命中共享 500ms 间隔。飞刃伤害独立于投射物强化，技能击杀正常掉落经验并计入击杀数。

`斩钢闪` 专属强化只会在解锁后进入奖励池。斩击和旋风共享普攻基础伤害、攻速、多重射击与弹速收益；穿透弹也会增加旋风可命中的目标数。被旋风击飞的敌人暂停追击且不会造成接触伤害，落地后恢复。

升级卡显示强化等级和实际数值变化。满级强化不再出现；剩余不足三项时显示实际数量。所有可用强化满级后经验条显示满格、等级标记 MAX，继续战斗且不再弹出升级面板。暂停升级、死亡与结算时技能、攻击和状态时间冻结，死亡重开清空全部强化与临时状态。

## 验证

运行 `npm test` 验证升级上限、候选耗尽、数值变化、穿透目标预算、重复命中保护和飞刃冷却；运行 `npm run build` 检查类型与生产构建。

启动开发服务器后，打开 `/tests/browser/logic.html` 运行真实 Phaser 场景回归检查。页面应显示 `ALL LOGIC CHECKS PASS`，覆盖升级按键隔离、连续升级、触控失焦与旋屏、HUD 重绘、小地图数据和死亡结算。此测试入口不包含在生产构建中。

## 战斗逻辑约定

- 刷怪点在玩家周围 400–850px 环内，边缘处重新选择合法方向，不直接裁切坐标；没有合法位置则跳过，且不消耗精英刷新次数。
- 玩家受到致命接触伤害后立即停止本帧攻击结算，清理已经死亡的实体后显示结算。
- 升级选择只响应新按键；切换升级面板或进入结算时清除残留动作按键，触控在失焦、隐藏和尺寸变化时释放。
- 小地图显示实际存活敌人与玩家位置，红蓝精英分别着色，每 100ms 刷新，暂停时冻结；静态 HUD 只在数值或布局变化时重绘。

当前没有主动技能、状态效果与手动暂停流程。
